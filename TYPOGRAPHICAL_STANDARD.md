## // hypermodern typographical standard

### principles

- **lowercase**: default to lowercase except for emphasis via `code formatting`
- **separators**: heavy horizontal rules `━━━━` for major divisions
- **headers**: `// prefix //` style for section markers
- **quotes**: multi-line technical content in code blocks
- **emphasis**: backticks for `technical terms`, bold for **concepts**
- **voice**: direct, technical, post-cynical optimism

### structure

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## // major section

introductory matter without ceremony

```
longer technical or philosophical content deserving
of the reader's focused attention
```

## // subsection

continuous prose with `inline code` where natural

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### influences

- gibson's pattern recognition typography
- unix manpage terseness
- demoscene ascii aesthetics
- post-medium publishing clarity

### usage

apply when documenting systems that exist at the intersection of technical excellence and aesthetic conviction. particularly suited for:

- nix configurations
- infrastructure as code
- developer tooling
- system architecture
